# YuNet face detector

`face_detection_yunet_2023mar.onnx` is the OpenCV Zoo YuNet model, bundled so
CPU face tracking works offline without another Python dependency or runtime
download. It uses OpenCV's DNN backend with the CPU target, not ONNX Runtime or
CUDA. This 2023 export is compatible with the project's OpenCV 4.12 dependency.
